# Demo Script

1. Start the app with `npm run dev`.
2. Open the Vite URL in a browser.
3. Show the React checkout summary and the separate merchant embed surface.
4. Inspect the `checkout-summary-panel` element in DevTools to show Shadow DOM.
5. Explain how the element receives checkout data through the `session` attribute.
6. Open Storybook to compare localized success and error states.
7. Run `npm run quality` for lint, type, unit, coverage, build, Storybook, and
   dependency gates.
8. Run `npm run test:e2e` for desktop/mobile browser regression and rendered
   accessibility checks.
